## 1. 绪论：人工智能与图灵测试

来源：PDF 第 2 页。来源：PDF 第 2 页第 1 项；Word 第 1 节。

### 用“定义—目标—模块—实例”组织答案

- 人工智能研究与构建能够感知、表示知识、推理、学习、规划并行动的系统。工程目标是让系统有效完成任务；科学目标是研究智能的原理与机制，不仅限于照搬人脑。
- 内涵是感知、学习、推理与决策等智能能力；外延是具备或利用这些能力的系统、任务与应用，例如语音助手、医学影像识别和自主机器人。
- 以自动驾驶为例：感知识别道路与行人，知识/世界模型表示交通环境，预测与规划选择轨迹，控制模块执行动作，学习模块利用数据改进系统。模块划分并非唯一。

### 智能系统的基本闭环

- 环境 → 感知 → 表示 / 推理 / 规划 → 行动 → 环境反馈

### 图灵测试

- 在经典文本交互设定下，评判者分别与人和机器对话，尝试区分身份。若机器在约定条件下难以被区分，可视为通过该测试。
- 测试关注可观察的语言行为，不直接证明意识、理解、真实性或所有领域的通用智能；结论必须写明任务、时长、评判方式与成功阈值。

### 搜索方法分类（Word 补充）

- 无信息搜索：BFS、DFS、一致代价搜索 UCS、迭代加深 IDS。
- 启发式搜索：贪心最佳优先搜索、A*。局部/随机优化：爬山、模拟退火、遗传算法等；详细条件见第 4 项。

### 自测与参考答案

**问：一个能流畅聊天的系统是否一定具有通用智能？**

答：不一定。流畅对话是行为能力证据，仍需分别评估推理、规划、泛化、可靠性与具身交互，不能由图灵测试直接推出全部能力。

## 2. 五种 Agent 与大模型的作用

来源：PDF 第 2 页。来源：PDF 第 2 页第 2 项；Word 第 2 节。学习型 Agent 的结构在此补充为经典四组件。

### 结构与实现对照

| 类型 | 主要依据 | 实现思路 / 局限 |
| --- | --- | --- |
| 简单反射型 | 当前感知 → 条件–动作规则 | 规则表或 if–else；缺少记忆，对部分可观测环境能力有限。 |
| 基于模型的反射型 | 历史内部状态 + 世界模型 + 当前感知 | 先更新内部状态，再匹配规则；依赖模型与状态估计。 |
| 目标驱动型 | 状态 + 目标 + 可执行动作模型 | 搜索/规划能实现目标的动作序列；目标达成不等于代价最小。 |
| 基于效用型 | 结果概率 + 效用函数 | 选择期望效用最大的动作；需刻画风险与多目标偏好。 |
| 学习型 | 经验与反馈 | 由性能元件、学习元件、评论元件和问题生成器共同改进行为；可叠加在其他结构上。 |

### 画图时保留这些信息通路

- 感知 → 条件–动作规则 → 动作
- 旧状态 + 上次动作 + 世界模型 + 当前感知 → 更新内部状态 → 规则 → 动作
- 内部状态 + 目标 + 动作模型 → 搜索 / 规划 → 动作
- 内部状态 + 结果预测 → 期望效用比较 → 动作
- 环境反馈 → 评论元件 → 学习元件 → 改进性能元件
- 问题生成器 → 建议探索动作 → 性能元件 → 环境

### 效用型 Agent 的决策

```text
a* = arg max_a Σ_s′ P(s′ | s, a) U(s′)
```

### LLM 可以放在哪些模块？

- 语言感知与语义表示：把自然语言任务整理为结构化目标和约束。
- 规划与工具调用：提出子任务、生成工具参数；执行结果必须反馈给状态模块。
- 记忆检索与反思：检索历史经验、总结反馈。LLM 的文本输出不等同于真实环境状态，外部校验、权限控制与停止条件仍有必要。

### 自测与参考答案

**问：学习型 Agent 的四个经典组件是什么？**

答：性能元件选择动作；评论元件依据性能标准评价行为；学习元件改进性能元件；问题生成器建议有信息价值的探索动作。它们不是简单串行的“感知→学习→动作”。

## 3. 搜索问题的形式化与基本概念

来源：PDF 第 2 页。来源：PDF 第 2 页第 3 项；Word 第 3 节。已修正八数码分支数与可达状态的简化说法。

### 问题定义

```text
问题 = (初始状态 s₀, 动作集 A(s), 转移模型 Result(s,a), 目标测试 Goal(s), 步代价 c(s,a,s′))
路径代价 g(n) = 从根到节点 n 的步代价之和
```

### 最容易混淆的概念

| 概念 | 含义 |
| --- | --- |
| 感知 / 状态 | 感知是传感器收到的观测，可能不完整或有噪声；状态是求解模型对环境的描述。 |
| 动作 / 转移 | 动作是可执行操作；转移模型描述动作如何改变状态。 |
| 状态空间 | 模型允许的状态集合；从特定初始状态可达的集合可能只是其中一部分。 |
| 搜索树 / 搜索图 | 树节点记录一条到达状态的路径，同一状态可重复出现；图搜索用已探索集或最佳代价表处理重复状态。 |
| 分支因子 b / 解深度 d | b 为每次展开的后继数（分析时常取最大值或有效值），d 为最浅解的边数。 |

### 八数码示例

- 状态：8 个数码和空格的排列。动作：将空格与上、下、左、右相邻数码交换；步代价通常为 1。
- 空格在角落有 2 个合法动作、边上有 3 个、中心有 4 个。不能笼统写“总是 3–4 个”。
- 9! 种排列并非都可从同一初态到达；对标准 3×3 八数码，给定目标有 9!/2 个同奇偶类的可达状态。
- 实现时节点通常含 state、parent、action、path cost；区分状态相等与节点相等，防止循环和重复展开。

### 自测与参考答案

**问：为什么两条不同路径可以对应同一个状态？**

答：状态只保留问题求解所需的环境信息，节点还记录到达它的路径。例如先向左再向右可回到原位置。图搜索应比较已知最佳代价，而不是把每条路径都当成新状态。

## 4. 搜索算法：A*、局部搜索与群体优化

来源：PDF 第 3 页。

### 搜索策略与最优性条件

| 方法 | 扩展依据 | 注意条件 |
| --- | --- | --- |
| BFS | 最浅节点，FIFO 队列 | 有限分支且有有限深度解时完备；等步长代价时最优，不能泛指最低代价路径。 |
| DFS | 最深节点，栈 | 空间通常较低；无限深路径/循环下不完备，通常不最优。 |
| UCS | 最小 g(n) | 在有限分支、正步代价有统一正下界等条件下完备且最优。 |
| IDS | 逐次增加深度限制 | 有限分支时结合 BFS 的浅层解搜索与 DFS 的低空间；等步长代价时最优。 |
| 贪心最佳优先 | 最小 h(n) | 只看估计剩余代价，不保证最优。 |
| A* | 最小 f(n)=g(n)+h(n) | 树搜索常用可接纳性；不重开节点的图搜索通常要求一致性。 |

### A* 条件与启发式支配

```text
可接纳：0 ≤ h(n) ≤ h*(n)，h(goal)=0
一致：h(n) ≤ c(n,n′) + h(n′)
若 0 ≤ h₁(n) ≤ h₂(n) ≤ h*(n)，则 h₂ 支配 h₁。
```

### 计算与比较

- 在相同条件下，较大的可接纳启发式通常减少必须扩展的节点；f=C* 边界上的平局处理可能影响节点数，不能无条件说“一定更快”。
- 八数码：错位数与曼哈顿距离都不计空格。曼哈顿距离是各数码到目标格子的行、列距离之和，通常不小于错位数。
- 例如目标为 1 2 3 / 4 5 6 / 7 8 □，当前为 1 2 3 / 4 5 6 / □ 7 8，错位数=2，曼哈顿距离=2。
- N 皇后局部搜索可用互相攻击的皇后对数作为冲突目标 h，越小越好。它不自动成为 A* 的可接纳代价估计，必须先定义动作与路径代价。

### A* 框架（支持发现更优路径后重开）

```text
g[start] = 0; parent[start] = 空
OPEN.push(start, priority=h(start), cost=0)
while OPEN 非空:
    n, popped_g = OPEN.pop_min_f()
    if popped_g != g[n]: continue  // 跳过过期队列条目
    if Goal(n): return 沿 parent 回溯的路径
    for each 后继 n′, 步代价 c:
        candidate = g[n] + c
        if candidate < g.get(n′, +∞):
            g[n′] = candidate; parent[n′] = n
            OPEN.push(n′, candidate + h(n′), candidate)
return 失败
```

### 原始最陡上升爬山（这里最大化 V）

```text
current = 初始状态
loop:
    next = 邻居中 V 最大者
    if 无邻居 or V(next) <= V(current): return current
    current = next
```

### 爬山的三个常见变种

- 随机爬山：从上升方向按规则随机选择，降低对单一路径的依赖。
- 首选爬山：随机生成邻居，遇到第一个更好邻居便移动，适合邻居非常多的情况。
- 随机重启爬山：多次从新初态出发，缓解局部最优。平台、山脊仍可能阻碍搜索；允许侧向移动时需设置步数上限。

### 模拟退火（最小化能量 E）

```text
current = 初始解
for t = 1, 2, ...:
    T = schedule(t)
    if T <= 0: return current
    next = 随机邻居(current)
    ΔE = E(next) - E(current)
    if ΔE <= 0 or Uniform(0,1) < exp(-ΔE/T):
        current = next
```

### 群体优化算法步骤

| 算法 | 步骤 | 机理 |
| --- | --- | --- |
| 遗传算法 GA | 编码/初始化 → 计算适应度 → 选择 → 交叉 → 变异 → 替换 → 终止判断 | 选择保留较优个体，交叉组合片段，变异保持多样性；注意约束可行性和早熟收敛。 |
| 蚁群算法 ACO | 初始化信息素 → 蚂蚁按概率构造解 → 评价 → 信息素挥发与增量更新 → 迭代 | 信息素正反馈利用好路径，挥发减弱历史锁定，启发信息提供局部引导。 |
| 粒子群 PSO | 初始化位置/速度 → 更新个体最优与群体最优 → 更新速度/位置 → 处理边界 → 迭代 | 惯性、个体经验和群体经验共同引导连续空间探索。 |

### 蚁群与粒子群常用形式

```text
ACO：pᵢⱼ ∝ τᵢⱼ^α ηᵢⱼ^β（仅对允许后继归一化）
τᵢⱼ ← (1−ρ)τᵢⱼ + Σ_k Δτᵢⱼᵏ
PSO：vᵢ ← ωvᵢ + c₁r₁(pbestᵢ−xᵢ) + c₂r₂(gbest−xᵢ)
xᵢ ← xᵢ + vᵢ
```

### 蒙特卡洛树搜索 MCTS

- 重复四步：选择（如 UCT）→ 扩展一个新节点 → 模拟/价值评估 → 将回报回传并更新访问次数。
- UCT 常用 Q̄(s,a) + c√(ln N(s) / N(s,a))；未访问动作优先探索，Q̄ 是平均回报而不是累计回报。
- 探索项鼓励尝试少访问动作，价值项利用已有好动作；预算结束后通常按访问次数等规则选根节点动作。

### 自测与参考答案

**问：可接纳但不一致的 h 能否直接用于不重开 CLOSED 节点的 A* 并保证最优？**

答：不能一般保证。可采用更优 g 值出现时重开节点的策略；若不重开，通常需一致性等充分条件。

**问：模拟退火为何可能接受更差的解？**

答：以 exp(−ΔE/T) 的概率接受变差移动，帮助逃离局部最优。温度降低后接受概率下降；有限运行和任意降温表不保证得到全局最优。

## 5. 约束满足问题 CSP

来源：PDF 第 4 页。

### 形式化

```text
CSP = (X, D, C)
X：变量集合；D：各变量的取值域；C：限制联合取值的约束。
```

### 地图着色

- 每个地区是一个变量，域为可用颜色；相邻地区满足 Xi ≠ Xj。完整且满足全部约束的赋值是解。
- 用回溯搜索逐个赋值，并结合前向检查或弧一致性传播，尽早排除不可能分支。

### 三类常见启发式

| 方法 | 选择对象 | 计算依据 |
| --- | --- | --- |
| MRV：最少剩余值 | 下一个变量 | 优先当前合法颜色数最少的地区，而不是初始域大小。 |
| 度启发式 | 变量，常用于 MRV 平局 | 优先与最多未赋值变量相邻/存在约束的变量。 |
| LCV：最少约束值 | 当前变量的取值 | 优先排除其他未赋值变量取值最少的颜色。 |

### 手算示例

- 变量 A 的可用域为 {红,绿}，邻居 B 的当前域为 {红}、C 为 {红,蓝}。A=红会删除 B、C 共 2 个取值且导致 B 无值；A=绿不删除任何值，因此 LCV 选择绿。
- 若对所有变量应用 MRV，B 仅剩一个值，应优先于 A；计算不同启发式时要写清“当前已经选择了哪个变量”。
- 弧一致性要求 Xi 域中的每个值都能在 Xj 的域中找到支持。局部一致性并不总能推出整个 CSP 有解。

### 自测与参考答案

**问：MRV 与 LCV 是否冲突？**

答：不冲突。MRV 决定先给哪个变量赋值，LCV 决定给已选变量尝试哪个值：前者优先难变量，后者优先对未来限制较少的取值。

## 6. 命题逻辑、归结反驳与怪兽世界

来源：PDF 第 4 页。

### 语法与语义

| 连接符 | 真值条件 |
| --- | --- |
| ¬P | 当且仅当 P 为假时为真。 |
| P∧Q | P、Q 都真才真。 |
| P∨Q | 至少一个为真；这里是包容或。 |
| P→Q | 仅 P 真且 Q 假时为假；等价于 ¬P∨Q。 |
| P↔Q | 两者真值相同；等价于两个方向的蕴含。 |

### 语义蕴含与语法推导

- KB ⊨ α 表示所有使 KB 为真的模型也使 α 为真；KB ⊢ α 表示可由选定的公理与推理规则导出 α。
- 演绎分离（Modus Ponens）：由 P、P→Q 推出 Q。可靠性要求推导不产生语义上错误的结论；完备性要求应有的语义结论都可推导。
- 归结反驳：将 KB∧¬α 化成 CNF 子句集，消去蕴含、内移否定、分配析取，反复归结。若得到空子句 □，则 KB ⊨ α。未在有限步骤内找到空子句，不等于已经证明不蕴含。

### 归结规则

```text
(A ∨ L), (B ∨ ¬L) ⟹ (A ∨ B)
```

### 怪兽世界中的简单证明（气流与陷阱）

```text
约定：B11 表示 (1,1) 有气流；P12、P21 表示相邻格有陷阱。
知识：B11 ↔ (P12 ∨ P21)，观测：¬B11。
CNF 中包含：(B11 ∨ ¬P12)，(B11 ∨ ¬P21)，(¬B11 ∨ P12 ∨ P21)。
证明 ¬P12：加入其否定 P12。
(B11 ∨ ¬P12) 与 P12 归结得 B11；B11 与 ¬B11 归结得 □。
故 KB ⊨ ¬P12。同理得 ¬P21。
```

### 画出世界再写知识库

- 先规定坐标、邻接规则和每个符号的含义。气流与陷阱、臭味与怪兽是不同的命题族，不能混用；“安全”通常还需同时排除怪兽等危险。

### 自测与参考答案

**问：从 P→Q 和 Q 能否推出 P？**

答：不能。这是肯定后件的错误。可能还有别的原因使 Q 成立。例如“有陷阱→有气流”并不能从有气流推出某个特定相邻格一定有陷阱。

## 7. 知识表示、本体与非单调推理

来源：PDF 第 4 页。

### 本体、类、子类与对象

- 本体描述领域中的概念、关系与约束。类表示对象集合；子类关系表示集合包含；对象（个体）是具体实体；“属于类”和“类是子类”是不同关系。
- 例：研究生 ⊆ 学生，张三 ∈ 研究生，因此张三 ∈ 学生；“张三是学生”不推出“学生是张三的子类”。

### 开放/封闭世界与默认推理

| 概念 | 含义与用途 |
| --- | --- |
| 封闭世界假设 CWA | 在适用范围内，未能证明为真的事实按假处理；常用于完整数据库查询。 |
| 开放世界假设 OWA | 缺失事实表示未知，不直接认定为假；适合不完整且持续扩展的知识。 |
| 单调推理 | 增加前提不撤销已有结论；经典逻辑具有此性质。 |
| 非单调推理 | 新信息可能撤回默认结论；如通常鸟会飞，得知是企鹅后撤回飞行判断。 |

### 语义网与知识图谱的逻辑基础

- RDF 用主语–谓语–宾语三元组表示事实；RDFS 提供类、子类、属性等基础语义；OWL（尤其 OWL DL）基于描述逻辑提供更强的概念约束与推理能力。
- 知识图谱是实体关系表示与相关技术的集合，实际系统可能采用 RDF 或属性图等，不是所有知识图谱都使用同一种逻辑或开放世界假设。

### 自测与参考答案

**问：知识库没有记录“小李会游泳”，能否断言他不会？**

## 8. 不确定性：概率图、CRF、损失与模糊逻辑

来源：PDF 第 5 页。

### 贝叶斯网络（有向无环图）

```text
P(x₁,…,xₙ) = ∏ᵢ P(xᵢ | Pa(xᵢ))
例：A→B，A→C，(B,C)→D
P(A,B,C,D)=P(A)P(B|A)P(C|A)P(D|B,C)
```

### 由联合分布得到边缘分布

- 对不关心的离散变量求和（连续变量积分），如 P(D)=Σ_A,B,C P(A,B,C,D)。不要把条件独立当成无条件独立。
- 练习：若 P(A=1)=0.3，P(B=1|A=1)=0.8，P(B=1|A=0)=0.2，则 P(B=1)=0.3×0.8+0.7×0.2=0.38。

### 马尔科夫网络与对数线性形式

```text
P(x) = (1/Z) ∏_C ψ_C(x_C)
ψ_C(x_C) = exp(Σ_k θ_k f_k(x_C))
Z = Σ_x ∏_C ψ_C(x_C)（配分函数）
```

### 线性链条件随机场

```text
P(y|x) = (1/Z(x)) exp[Σ_t Σ_k λ_k f_k(yₜ₋₁,yₜ,x,t)]
Z(x) = Σ_y exp[Σ_t Σ_k λ_k f_k(yₜ₋₁,yₜ,x,t)]
```

### 三种图模型的区别

- 贝叶斯网络用 DAG 与局部条件概率描述联合分布；马尔科夫网络用无向图与非负势函数（对数线性形式通常为正）描述联合分布；CRF 直接对给定 x 的标签条件分布建模。
- CRF 的 Z 依赖 x，并对整个候选标签序列求和；不能把它写成仅对当前一个标签求和。

### 交叉熵

```text
多分类：L = −(1/N) Σᵢ Σ_k yᵢₖ log pᵢₖ
二分类：L = −(1/N) Σᵢ [yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ)]
```

### 过拟合：原因与应对

- 模型容量相对数据过大、样本少/噪声大、训练过久、反复依据验证集选择配置，都可能导致对样本偶然模式的过度适应。
- 使用更多且有代表性的数据、数据增强、正则化、早停、容量控制、交叉验证等。训练误差小不等于泛化误差小；数据泄漏也会造成虚假的高分。

### 常见 T 范（模糊“与”）和 S 范（模糊“或”）

| 类型 | T(a,b) | 对应 S(a,b) |
| --- | --- | --- |
| 最小 / 最大 | min(a,b) | max(a,b) |
| 乘积 / 概率和 | ab | a+b−ab |
| Łukasiewicz | max(0,a+b−1) | min(1,a+b) |

### 计算与公理

- a,b∈[0,1]。T 满足交换、结合、单调及 T(a,1)=a；S 的单位元是 0。上述配对在标准否定 1−a 下满足 S(a,b)=1−T(1−a,1−b)。
- 取 a=0.3,b=0.7：三种 T 分别为 0.3、0.21、0；三种 S 分别为 0.7、0.79、1。隶属度表示程度，不等于事件发生概率。

### 自测与参考答案

**问：CRF 与 HMM 的主要建模差异是什么？**

答：HMM 对观测和隐藏状态的联合分布建模，通常带有条件独立假设；CRF 建模 P(y|x)，可以使用更灵活、相互依赖的观测特征。

**问：二分类 y=1、p=0.8 的单样本交叉熵是多少？**

答：−ln(0.8)≈0.2231（使用自然对数）。只保留真实类别对应的对数概率项。

## 9. 深度学习：表达能力、激活与归纳偏置

来源：PDF 第 6 页。

### 为什么深层结构有效？

- 多层组合能逐级构造特征，在具有组合结构的任务上可能比浅层网络更高效地表示函数。表示能力、可优化性和泛化能力是三个不同问题。
- 深层网络并非天然比浅层网络更易训练。现代训练依赖合适初始化、非饱和激活、归一化、残差连接、优化器、数据与算力；解释题要说明这些条件。
- 万能近似定理在相应激活与紧致域等条件下说明足够宽的浅层网络能近似连续函数，并不保证训练能找到该解、所需宽度合理或泛化良好。

### ReLU 网络的线性区域：先写清假设

```text
一维输入、单隐藏层、m 个 ReLU：至多 m+1 个线性区间。
d 维输入、单隐藏层、m 个超平面处于一般位置：
区域数上界 R ≤ Σ_{j=0}^{min(d,m)} C(m,j)。
一维输入、多层宽度 n₁,…,nL：粗略上界 R ≤ ∏ₗ(nₗ+1)。
```

### 区域数的答题步骤

- 先确认输入维数、层数、各层宽度、激活函数，再计算界或具体断点。对给定权重求实际区域数时，还要检查断点是否可达、重合、被消去。
- 例：一维输入，浅层有 3 个 ReLU，最多 4 个区间；两层各 3 个 ReLU 的上述粗界是 16，不能据此声称一定有 16 个区间。深层精确计数有更多条件。
- 提纲提示参考 Understanding Deep Learning 的 Deep Neural Networks / Shallow vs. deep 部分；本页给出常用界，不冒充该章所有架构的精确公式。

### 激活函数

| 名称 | 形式 | 特点 |
| --- | --- | --- |
| Sigmoid | σ(x)=1/(1+e^(−x)) | 值在 (0,1)，大绝对值处饱和；常用于门控。 |
| Tanh | tanh(x)=(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ) | 零中心，仍会饱和。 |
| ReLU | max(0,x) | 正半轴导数 1；负半轴可能出现“死亡”单元。 |
| Leaky ReLU | max(αx,x)，0<α<1 | 负半轴保留小梯度。 |
| GELU | xΦ(x) | Φ 为标准正态 CDF；常见于 Transformer。 |
| SiLU / Swish | xσ(x) | 平滑门控激活。 |

### Softmax 与数值稳定性

```text
softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)
稳定实现：令 m=maxⱼ zⱼ，用 exp(zᵢ−m) 计算相同比值。
```

### 结构与归纳偏置

| 结构 | 适用数据 | 偏置与限制 |
| --- | --- | --- |
| CNN | 图像、局部网格、时序局部模式 | 局部连接与权重共享；卷积在合适边界条件下具有平移等变性，池化可带来局部不变性。 |
| RNN | 有序序列与时间序列 | 递归状态与时间权重共享，偏向顺序依赖；训练跨时间串行，长依赖梯度困难。 |

### 自测与参考答案

**问：一维输入、单层 4 个 ReLU 一定有 5 个线性区间吗？**

答：不一定，5 是上界。断点可能重合、落在输入域外，输出层组合也可能使相邻区域的斜率变化抵消。

**问：为什么 softmax 减去最大 logit 不改变结果？**

答：分子和分母都乘以同一个 exp(−m)，比值不变，同时避免直接计算很大的指数造成溢出。

### 概念与典型任务

| 概念 | 核心与例子 |
| --- | --- |
| 无监督学习 | 从无人工任务标签的数据中发现结构；聚类、降维、密度估计、表示学习。 |
| 传统生成模型 | 朴素贝叶斯、GMM、HMM 等对数据或联合分布建模；可用于分类、聚类、序列建模。 |

### KL 散度与 InfoNCE

```text
D_KL(P∥Q) = Σ_x P(x) log[P(x)/Q(x)]
InfoNCE：Lᵢ = −log { exp(sim(zᵢ,zᵢ⁺)/τ) / Σ_{k∈候选集} exp(sim(zᵢ,z_k)/τ) }
```

### 计算与比较

- KL 非负且通常不对称，不是距离度量；若某处 P>0 而 Q=0，则 KL 为无穷。约定 P=0 的项贡献为 0。
- 例：P=(0.5,0.5)，Q=(0.25,0.75)，D_KL=0.5ln2+0.5ln(2/3)≈0.1438 nat。
- InfoNCE 分母包含正样本与选定负样本；温度 τ>0 调整分布尖锐程度。样本构造不当会引入假负样本。
- 监督学习通常使用给定输入–标签对；强化学习接收动作影响下的、可能延迟的奖励，涉及探索、信用分配与非独立同分布交互数据。
- 自监督学习从数据本身构造预测目标，常归入广义无监督学习，但训练时仍使用显式的构造标签。

### 自测与参考答案

**问：目标任务数据很少时，如何迁移预训练模型？**

答：可先冻结主干训练小任务头，再按验证集表现逐步解冻或采用参数高效微调。需检查领域差异、数据泄漏和负迁移，不是所有预训练模型都适合。

## 11. Transformer、CNN 与循环网络结构

来源：PDF 第 8 页。

### RNN 长序列的困难与编码器–解码器

- RNN 跨时间反向传播时梯度连乘可能消失或爆炸；串行状态更新限制训练并行。固定长度状态还可能成为编码器–解码器的信息瓶颈。
- 编码器把输入序列映射为表示；解码器结合表示与此前输出预测后续词元。带注意力的解码器可访问整组编码状态，不仅依赖一个固定向量。

### 缩放点积注意力

```text
Q=XW_Q，K=XW_K，V=XW_V
Attention(Q,K,V)=softmax(QKᵀ/√d_k + Mask)V
MultiHead=Concat(head₁,…,head_h)W_O
```

### Q、K、V 的直观含义

- 可把选择性注意理解为“当前想找什么”匹配“候选内容的索引/特征”，再汇聚内容：Q 是查询，K 用于匹配，V 是被加权聚合的信息。它是解释性类比，不是大脑实现的严格等同。
- 自注意力的 Q、K、V 来自同一序列；交叉注意力中 Q 通常来自解码器，K、V 来自编码器。因果 Mask 阻止位置看到未来词元。

### 原始 Transformer 的结构示意（注意区分现代变体）

- 输入词元 → 嵌入 + 位置信息 → 多头自注意力 → 残差 + 归一化 → 前馈网络 → 残差 + 归一化 → 编码表示
- 右移的输出词元 → 嵌入 + 位置信息 → 掩码自注意力 → 残差 + 归一化 → 编码器–解码器交叉注意力 → 残差 + 归一化 → 前馈网络 → 残差 + 归一化 → 线性层 + Softmax

### 画图时加上的连线

- 编码器最终表示向解码器交叉注意力提供 K、V，解码器当前表示提供 Q；各子层有残差旁路，编码器和解码器模块可堆叠 N 次。
- 上图采用原始后归一化示意；许多现代模型用 Pre-LN / RMSNorm。Decoder-only 模型没有编码器交叉注意力，不能画成所有 LLM 都是完整原始结构。

### Transformer 与 RNN

| 维度 | Transformer | RNN |
| --- | --- | --- |
| 训练计算 | 序列内注意力计算可并行 | 隐藏状态跨时间串行 |
| 长距离依赖 | 注意力可直接连接远位置 | 需经过多步递归链 |
| 代价 | 标准全注意力的分数矩阵随长度为 O(n²) | 固定隐藏宽度时递归步数随 n 线性 |
| 位置信息 | 通常需显式位置机制 | 递归顺序天然携带时序结构 |
| 生成推理 | 自回归解码仍逐词元，常用 KV cache | 可在线更新固定大小隐藏状态 |

### CNN 与循环单元的作图骨架

- 图像 → 卷积提取局部特征 → 激活 → 下采样 / 池化 → 重复特征块 → 全局池化 / 展平 → 任务头
- xₜ + hₜ₋₁ → RNN 非线性变换 → hₜ → 输出 / 下一时刻
- xₜ + hₜ₋₁ → LSTM 门控 → 更新细胞状态 cₜ → 输出隐藏状态 hₜ

### 进一步复现计算图

- 第 24 项列出 RNN、LSTM、GRU 的全部门控方程与状态通路。练习时按方程逐条画加法、逐元素乘法和非线性节点；CNN 要标出特征图尺寸与通道数变化。

### 自测与参考答案

**问：Transformer 是否在推理时也能一次并行生成所有自回归词元？**

答：通常不能。下一词元依赖先前生成结果；训练时的 teacher forcing 可并行计算各位置损失，不等同于自回归生成并行。

## 12. 强化学习：Q-learning 与 DQN

来源：PDF 第 9 页。

### Q-learning 更新

```text
Q(s,a) ← Q(s,a) + α [r + γ max_a′ Q(s′,a′) − Q(s,a)]
终止转移的目标 y = r，不再引导后继价值。
```

### 表格型 Q-learning

```text
初始化 Q(s,a)
for each episode:
    初始化状态 s
    while 未终止:
        用 ε-greedy 从 Q(s,·) 选择 a
        执行 a，观察 r,s′,done
        y = r if done else r + γ max_a′ Q(s′,a′)
        Q(s,a) += α × (y − Q(s,a))
        s = s′
```

### DQN 的核心训练循环

```text
初始化在线网络 Qθ、目标网络 Qθ⁻（复制 θ）与回放池 D
循环与环境交互:
    用 ε-greedy(Qθ) 选择并执行动作
    把 (s,a,r,s′,done) 存入 D
    从 D 随机采样小批量转移
    y = r + γ(1−done) max_a′ Qθ⁻(s′,a′)
    最小化 (y − Qθ(s,a))² 或 Huber 损失，更新 θ
    每隔 C 步复制 θ⁻ ← θ（或采用软更新）
```

### 为什么需要这些部件？

- 经验回放降低连续样本的相关性、提高数据复用率；目标网络减缓训练目标随在线网络同步变化造成的不稳定。
- Q-learning 为离策略方法：行为策略可以探索，更新目标使用贪心动作。DQN 用神经网络替代表格，但不自动继承表格情形的收敛保证。
- 区分真实终止与因时间上限截断：若任务本来还可继续，截断是否停止 bootstrap 需按环境语义处理。

### 自测与参考答案

**问：α=0.1、γ=0.9、旧 Q=2、r=1、max Q(s′,·)=4，非终止时新 Q 为多少？**

答：目标 y=1+0.9×4=4.6，TD 误差=2.6，新 Q=2+0.1×2.6=2.26。若为真实终止，目标为 1，新 Q 为 1.9。

### LoRA：低秩增量

```text
W₀ ∈ R^(d_out×d_in)，ΔW = (α/r)BA
A ∈ R^(r×d_in)，B ∈ R^(d_out×r)，r ≪ min(d_in,d_out)
y = W₀x + (α/r)BAx
可训练参数：r(d_in+d_out)，而非 d_in×d_out。
```

### 模型技术出处（公开版本文档）

- [DeepSeek-R1 官方仓库与技术报告入口](https://github.com/deepseek-ai/DeepSeek-R1)
- [DeepSeek-V3 官方仓库与技术报告入口](https://github.com/deepseek-ai/DeepSeek-V3)

### LoRA 的过程

- 加载预训练模型并冻结选定基础权重；在选定线性层插入低秩适配器；初始化一侧随机、另一侧为零，使初始增量为零且仍能学习。
- 使用目标任务数据训练适配器，依据验证集调 r、α、学习率等；推理时加载适配器，条件允许时把增量合并回原权重。
- LoRA 节省可训练参数及相关梯度/优化器状态，但仍需要存放和计算基础模型。量化基础权重再训练适配器的 QLoRA 与普通 LoRA 要区分。

## 18. 名词解释：RAG、思维链、规划等

来源：PDF 第 11 页。

### 六个术语的最小完整答案

| 术语 | 机制 | 局限 / 易错点 |
| --- | --- | --- |
| RAG：检索增强生成 | 将问题相关的外部资料检索出来，作为上下文供生成模型使用。 | 检索、切分、排序和来源质量影响结果；不能保证消除幻觉，也不必更新模型权重。 |
| 思维链 CoT | 把复杂求解组织为中间推理步骤的提示或生成方式。 | 可见步骤不一定忠实反映内部过程，也不自动保证结论正确；需用结果或外部方法验证。 |
| 自动规划 | 根据初始状态、目标、动作前提与效果，求可执行动作序列或策略。 | 不同于只生成一段看似合理的自然语言计划。 |
| 图灵测试 | 在约定的对话判别实验中测试机器是否难以与人区分。 | 是行为测试，不直接测量意识或全部智能。 |
| 词嵌入 | 把词/词元映射为连续向量，捕捉一定的语义或分布关系。 | 静态嵌入与上下文化表示不同；向量接近不保证逻辑等价。 |
| 梯度消失 / 爆炸 | 链式求导中多次乘积使梯度极小或极大。 | 可用合适初始化、残差连接、门控、归一化；裁剪主要应对爆炸。 |

### RAG 的基本流水线

- 资料切分与建索引 → 问题检索 → 可选重排序 → 构造带来源上下文 → 生成与核验

### 梯度连乘的直觉

```text
∂h_T/∂h_t = ∏_{k=t+1}^T (∂h_k/∂h_{k−1})
反复乘以收缩/放大的 Jacobian，可能导致梯度消失/爆炸；需结合谱性质与非线性分析。
```

### 自测与参考答案

**问：RAG 与微调分别适合解决什么问题？**

答：RAG 更适合引入可更新、可追溯的外部知识；微调调整参数以改善行为、风格或特定任务能力。两者可组合，且都需要验证数据与输出质量。

## 20. 指代消解、最一般合一与微调方法

来源：PDF 第 12 页。

### 指代消解

- 确定代词、指示词或名词短语指向的实体。例：“小李把书还给小王，因为他看完了。”其中“他”可能指小李，须结合上下文消除歧义，不能仅按最近名词机械决定。
- 解题时列候选实体，结合句法、语义、常识和上下文约束，并说明仍存在的歧义。

### 最一般合一 MGU

```text
令两个一阶项/原子在替换 θ 后相同：θ(E₁)=θ(E₂)。
MGU 不引入不必要的具体化；其他合一替换可由它进一步实例化得到。
例：P(x,f(y)) 与 P(a,f(b)) 的 MGU 为 {x↦a, y↦b}。
```

### 合一的边界与步骤

- 逐项比较：常量必须一致、函数符号与元数必须匹配；变量可替换，但应做 occurs-check，防止变量出现在自己的替换项中。
- P(x,x) 与 P(a,b) 在 a、b 为不同常量时不能合一；x 与 f(x) 在通常的有限项一阶逻辑中不能合一。
- 多步替换要复合并传播，例如 {x↦y} 后又得 {y↦a}，最终 x 也应替换为 a。

### 微调路线比较

| 方法 | 优点 | 局限 / 场景 |
| --- | --- | --- |
| 全参数微调 | 调整能力强，灵活适配领域和任务 | 显存/优化器成本高，有遗忘风险；适合资源充足且数据可靠的场景。 |
| LoRA / QLoRA | 只训练低秩增量；QLoRA 进一步量化冻结主干 | 依赖层选择、秩和量化配置；适合资源有限的领域/任务适配。 |
| Adapter | 在网络中插入小瓶颈模块，任务参数可分离 | 可能增加推理结构与延迟；适合多任务模块化适配。 |
| Prompt / Prefix tuning | 学习连续提示或前缀，训练参数少 | 效果依模型规模和任务而异；不是仅手工写一句提示词。 |

### 不要混淆两个分类维度

- SFT（监督微调）、偏好优化等描述训练目标/数据方式；全参数、LoRA、Adapter 等描述更新哪些参数。可以使用 LoRA 完成 SFT，两者不是互斥类别。

### 自测与参考答案

**问：P(x,x) 与 P(y,a) 的一个 MGU 是什么？**

答：可得到 {x↦a, y↦a}。先从第一位置得到变量联系，再把第二位置的约束传播到两者；必须保证替换后两个原子完全一致。

## 23. AI 芯片、编译器与生成式模型

来源：PDF 第 14 页。

### 按常见计算架构举例（分类并非唯一）

| 类别 | 计算特点 | 适用考虑 |
| --- | --- | --- |
| CPU | 通用指令、复杂控制、缓存层次与较强单线程能力 | 调度、预处理与通用计算；矩阵吞吐/能效受具体型号影响。 |
| GPU | 大量并行计算单元，SIMT 与专用矩阵运算单元 | 高吞吐张量运算与大规模训练/推理；注意带宽与数据搬运。 |
| 专用 AI ASIC / NPU（如脉动阵列设计） | 面向特定张量数据流与低精度运算优化 | 能效与吞吐较高，但通用性、算子覆盖和生态有取舍。 |

### AI 编译器的常见结构

- 框架 / 模型导入 → 高层计算图 IR → 图优化与自动微分相关处理（视系统） → 算子 / 张量 IR → 调度与低层优化 → 硬件代码生成 → 运行时执行

### 编译器的主要作用

- 把高层模型变换为目标硬件可高效执行的程序：图简化、常量折叠、算子融合、布局与精度优化、内存规划、并行调度及代码生成。
- 并非每个编译器都覆盖所有阶段；自动微分也可能由框架完成。算子库、编译器、运行时与驱动有不同职责。

### 术语补充

| 术语 | 核心解释 |
| --- | --- |
| 词元 Token | 分词器处理的基本离散单位，可是子词、字符、字节片段或特殊标记；不等于一个自然语言单词或汉字。 |
| 扩散模型 | 正向逐步加噪，学习反向去噪/得分等过程，再从噪声逐步采样生成数据。 |
| 具身智能 | 通过身体与环境的感知–行动闭环实现智能，见第 15 项。 |
| 生成式人工智能 | 学习数据分布或条件分布以生成文本、图像、音频等；可用自回归、扩散、VAE、GAN 等路线。 |

### 扩散模型常用噪声参数化

```text
xₜ = √ᾱₜ x₀ + √(1−ᾱₜ) ε，ε∼N(0,I)
常见简化训练目标：E[∥ε−εθ(xₜ,t)∥²]
```

### 生成式 AI 的技术特点

- 条件生成、概率性采样、可迁移表示与多模态建模是常见特征；输出质量与真实性不是同一指标，需检验一致性、偏差、版权/数据来源与使用场景。

### 自测与参考答案

**问：编译器优化为什么可能在权重不变时仍显著加速模型？**

答：它可以通过算子融合减少中间张量读写，调整数据布局、并行策略和内存分配，并为硬件选择高效内核；这些改变针对执行过程，不必改变模型所表达的函数。

## 24. 综合问答：循环单元、归一化、训练与系统

来源：PDF 第 15–18 页。第 24 项跨 PDF 第 15–18 页；对“更易训练”“小随机数不可取”“测试集只能用一次”等表述补充了适用条件。

### ① 原始 RNN：状态递归

```text
hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)
可选输出：oₜ = Wₒhₜ + bₒ
```

### ① LSTM：遗忘、输入、输出三道门

```text
fₜ = σ(W_f[xₜ;hₜ₋₁]+b_f)
iₜ = σ(W_i[xₜ;hₜ₋₁]+b_i)
c̃ₜ = tanh(W_c[xₜ;hₜ₋₁]+b_c)
cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ
oₜ = σ(W_o[xₜ;hₜ₋₁]+b_o)
hₜ = oₜ⊙tanh(cₜ)
```

### ① GRU：一种常用约定（更新门也有相反记号约定）

```text
zₜ = σ(W_zxₜ + U_zhₜ₋₁ + b_z)
rₜ = σ(W_rxₜ + U_rhₜ₋₁ + b_r)
h̃ₜ = tanh(W_hxₜ + U_h(rₜ⊙hₜ₋₁) + b_h)
hₜ = (1−zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ
```

### ① 按方程画计算图：显式标出门、乘法与加法

- xₜ 与 hₜ₋₁ → 仿射变换 + tanh → hₜ（RNN）
- cₜ₋₁ → × fₜ → + iₜ × c̃ₜ → cₜ → tanh 后 × oₜ → hₜ（LSTM）
- hₜ₋₁ → × (1−zₜ) → + zₜ × h̃ₜ → hₜ（GRU）
- hₜ₋₁ → × rₜ → 与 xₜ 计算候选 h̃ₜ → 候选分支

### ① 为什么改进？

- LSTM 的细胞状态提供可门控的加性路径；沿直接细胞通路的局部导数为 fₜ，有利于在 fₜ 接近 1 时保留梯度，但完整导数还有经门控等路径的项，不能说彻底解决梯度问题。
- GRU 合并细胞与隐藏状态，减少门与参数；计算与存储通常更省，是否优于 LSTM 取决于任务，不能笼统称为精度更高。
- GRU 文献中 z 的含义可能是保留率或写入率；写方程和画图时必须使用同一约定。部分实现还在候选计算的重置位置上存在差异。

### ② 标准化与网络归一化

```text
标准化：x′=(x−μ)/√(σ²+ε)
可学习仿射：y=γx′+β
Min–max：x′=(x−min)/(max−min)
RMSNorm：y=γ⊙x/√(mean(x²)+ε)（不减均值）
```

### ② 常见方法与作用轴

| 方法 | 统计范围 | 使用考虑 |
| --- | --- | --- |
| 输入标准化 / Min–max | 按特征用训练集估计统计量 | 改善尺度差异；不能用测试集估计预处理参数。 |
| BatchNorm | 按通道对批及相应空间轴统计 | 训练/推理统计不同；小 batch、序列变长等场景需谨慎。 |
| LayerNorm | 每个样本/位置的特征维度 | 不依赖 batch 统计，常用于序列模型。 |
| RMSNorm | 每个位置的特征均方根 | 省略均值中心化，常见于大模型。 |
| GroupNorm / InstanceNorm | 按通道组 / 单实例通道统计 | 分别适合小批图像训练等不同需求。 |

### ② 作用与使用条件

- 归一化可改善数值尺度、优化条件与训练稳定性，但不保证总能提高精度，也不能替代合适初始化和学习率。
- 特征量纲相差大、训练不稳定、模型结构明确设计了归一化层时尤其需要考虑；统计轴、ε、训练/推理模式必须匹配。

### ③ 大模型系统的软件与硬件层次

- 应用 / Agent / 服务接口 → 模型与训练/推理框架 → 编译器 + 算子库 + 分布式运行时 → 驱动与通信软件 → CPU / 加速器 / 内存 / 存储 / 网络

### ③ 系统组成与职责

- 系统还包括数据采集清洗、存储与调度、训练检查点、评测、部署、监控。训练与服务可能采用不同的并行策略和软硬件配置。
- AI 编译器通常位于框架/模型表示与硬件执行之间，进行图级和算子级变换；实际系统可能采用 JIT、AOT 或混合模式。

### ④ 训练步骤与超参数

- 数据收集与权限/质量检查 → 清洗去重、划分与分词 → 架构与初始化/预训练权重 → 设置目标和优化器 → 前向、计算损失、反向、更新 → 验证、检查点、早停/选择 → 独立测试 → 部署监控。
- 大模型生命周期还可包含预训练、监督微调和偏好对齐，不是每个任务都必须从头执行全部阶段。
- 超参例：学习率及其调度、batch size、权重衰减、训练步数、上下文长度、LoRA 秩。权重参数由训练更新，超参由外部选择。

### ④ 常见目标函数

```text
自回归语言建模：L = −Σₜ log pθ(xₜ | x₍<t₎)
均方误差：MSE=(1/N)Σᵢ∥ŷᵢ−yᵢ∥²
其他：交叉熵、对比损失、扩散去噪损失、偏好学习目标；按任务选择。
```

### ④ / ⑥ 三类优化器

| 优化器 | 更新思路 | 优点与注意点 |
| --- | --- | --- |
| SGD / Momentum | vₜ=βvₜ₋₁+gₜ，θ←θ−ηvₜ（一种约定） | 状态较少，动量平滑梯度；需合理学习率调度。 |
| RMSProp | vₜ=βvₜ₋₁+(1−β)gₜ²；按 √vₜ 缩放梯度 | 对各坐标自适应步长，适合非平稳梯度；仍需调参。 |
| Adam / AdamW | 结合一阶动量与二阶平方梯度估计并做偏差修正；AdamW 解耦权重衰减 | 常见于大模型训练，适应不同梯度尺度；优化器状态占用显存。 |

### Adam 的核心公式

```text
mₜ=β₁mₜ₋₁+(1−β₁)gₜ；vₜ=β₂vₜ₋₁+(1−β₂)gₜ²
m̂ₜ=mₜ/(1−β₁ᵗ)；v̂ₜ=vₜ/(1−β₂ᵗ)
θₜ=θₜ₋₁−η m̂ₜ/(√v̂ₜ+ε)
AdamW 另施加与梯度自适应缩放解耦的权重衰减。
```

### ⑤ 过拟合与尖锐极小值

- 过拟合：训练表现改善但未见数据表现不相应改善甚至恶化；措施见第 8 项，也可采用高质量数据、早停、适度参数高效微调和正则化。
- 尖锐极小值：参数附近小扰动可使损失显著上升。可讨论 SGD 噪声、SWA、SAM 等方法；平坦性受参数重缩放影响，不能把“平坦”当作泛化充分条件。

### SAM 的优化思想

```text
min_θ max_{∥ε∥≤ρ} L(θ+ε)
实践中近似沿最坏邻域扰动方向评估并更新，使局部邻域损失更稳定。
```

### ⑥ 简化模型与泛化：给出三条机制

- 容量控制：减少层数/宽度或采用低秩/稀疏约束，限制可拟合的函数族。
- L1/L2 正则化或权重衰减：鼓励稀疏或较小权重，限制有效复杂度；Adam 下 L2 与解耦衰减一般不等价。
- Dropout：训练时随机屏蔽单元，抑制共适应，可视作多子网络集成的近似效果；它不等于推理时删除固定一批神经元。
- 剪枝和蒸馏也可压缩模型，但压缩不自动提高泛化；需要重新验证任务表现。

### ⑥ 初始化与数据划分的条件

- 对称隐藏单元若全零初始化会产生相同激活/梯度，难以学到不同特征；但这不表示偏置或 LoRA 的一个因子也绝不能置零。
- “小随机数”不是一概不可取，问题是与层宽、层数和激活不匹配的任意过小方差可能衰减信号。Xavier 常用方差约 2/(fan_in+fan_out)，ReLU 的 He 初始化常用 2/fan_in。
- 训练集用于梯度更新，验证集用于选择超参与模型，测试集用于最终独立评估。提纲中的“测试集只能用一次”应理解为不能反复据测试结果调参；一旦它参与选择，需新的未污染留出集。并非每次评估后机械地把同一批样本重新打乱即可。

### ⑥ 大模型微调与优化技术（避免与优化器混淆）

| 类别 | 至少三项 | 作用 |
| --- | --- | --- |
| 微调方法 | 全参数、LoRA/QLoRA、Adapter、Prompt/Prefix tuning | 调整全部或部分参数/连续提示，优缺点与场景见第 20 项。 |
| 模型/执行优化 | 量化、剪枝、知识蒸馏 | 分别降低数值位宽、减少结构/参数、把教师能力迁移给学生；质量需复测。 |
| 系统优化补充 | 算子融合 / 高效注意力、KV cache、并行与批处理 | 分别减少内存搬运、复用历史计算、提高硬件利用率；受内存与延迟约束。 |

### ⑥ AI 编译器与传统 C 编译器：五个常见差异

| 比较轴 | AI 编译器的常见侧重 | 传统 C 编译器的常见侧重 |
| --- | --- | --- |
| 输入抽象 | 计算图、张量运算、模型与形状 | 源语言语法、控制流、指针与标量/数组 |
| 中间表示 | 图 IR、张量 IR、多层逐步下降 | 控制流/SSA 等 IR；现代系统也可共用底层 IR |
| 优化重点 | 算子融合、布局、张量切分、内存与带宽 | 常量传播、循环、控制流与寄存器等通用优化 |
| 目标硬件 | GPU、NPU、TPU 等异构加速器与张量单元 | 通用 CPU 为典型目标，也可面向 GPU 等 |
| 语义与运行时 | 形状专门化、混合精度、自动调优与算子运行时 | 语言语义、ABI、链接与通用运行时；也支持 JIT/向量化 |

### 比较题结论

- 这是侧重点比较，不是绝对互斥：AI 编译器常复用 LLVM/MLIR 等基础设施，传统编译器也能做并行和向量化。

### 自测与参考答案

**问：LSTM 中 fₜ≈1、iₜ≈0 时，细胞状态有何变化？**

答：沿直接通路 cₜ≈cₜ₋₁，有利于保留长期信息；hₜ 还受输出门与 tanh 影响。

**问：为什么不能用测试集选学习率？**

答：这样会让测试集参与模型选择，破坏独立评估的意义。应在验证集选择学习率，再用未参与选择的测试集评估。

**问：小 batch 时，BatchNorm 与 LayerNorm 有什么区别？**

答：BatchNorm 的批统计可能不稳定，且训练/推理统计方式不同；LayerNorm 在单个样本/位置的特征维度统计，不依赖 batch 大小，但是否适合还取决于网络结构。
